### Available Operations

* [responses](#responses) - Responses

## responses

Generate a model response from text or image inputs. Follows the OpenAI Responses API format, with support for streaming, function and custom tool calls, structured outputs, and reasoning controls.

### Example Usage

<!-- UsageSnippet language="python" operationID="containerResponses" method="post" path="/v1/responses" example="Example" -->
```python
import os

from friendli import SyncFriendli

with SyncFriendli(
    token=os.getenv("FRIENDLI_TOKEN", ""),
) as friendli:
    res = friendli.container.responses.responses(
        input_="Hello!", model="(adapter-route)", additional_properties={}
    )

    # Handle response
    print(res)
```

## stream

Generate a model response from text or image inputs. Follows the OpenAI Responses API format, with support for streaming, function and custom tool calls, structured outputs, and reasoning controls.

### Example Usage

<!-- UsageSnippet language="python" operationID="containerResponsesStream" method="post" path="/v1/responses#stream" example="Example" -->
```python
import os

from friendli import SyncFriendli

with SyncFriendli(
    token=os.getenv("FRIENDLI_TOKEN", ""),
) as friendli:
    res = friendli.container.responses.stream(
        input_="Hello!", stream=True, model="(adapter-route)", additional_properties={}
    )

    with res as event_stream:
        for event in event_stream:
            # handle event
            print(event, flush=True)
```
